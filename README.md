# 具身智能与机器人安全（Embodied AI / Robot Security）

本仓库整理「网络空间安全 × 机器人 / 具身智能」的研究方向，供学生选题与执行参考。

核心优势：
- 安全学生可以主要做攻击设计与算法部分
- 合作方提供人形机器人、机器狗等真实硬件，可做最终物理验证
- 目前真实人形 / 机器狗上的系统攻击工作较少，差异化空间存在

## 背景与意义

具身智能正在快速落地（人形机器人、机器狗、工业机器人）。一旦模型或系统被攻击，后果不再是错误文本，而是物理世界中的错误动作、人身伤害或财产损失。

相比纯数字大模型安全，具身安全有更清晰的经济与实际价值，也更容易形成「安全 × 机器人」的个人学术标签。

## 安全问题分类（按层级）

| 层级 | 典型问题 | 攻击例子 | 学生可行性 | 优先级建议 |
|------|----------|----------|------------|----------|
| **1. 感知层** | 传感器欺骗、视觉对抗、环境提示注入 | 对抗补丁、激光/声音欺骗、海报文字触发错误感知 | 中高 | 可做 |
| **2. 认知 / 模型层** | VLA / World Model 投毒、后门、越狱 | 在遥操作或仿真数据中植入触发器；对抗补丁攻击共享编码器 | **高** | **最推荐第一阶段** |
| **3. 规划层** | 任务规划被操纵、越狱后执行危险计划 | 语音/文本越狱，让机器人规划出危险路径或动作 | **高** | 推荐 |
| **4. 行动 / 控制层** | 控制指令被篡改、执行层劫持 | ROS 2 消息注入、动作序列替换 | 中 | 可做 |
| **5. 系统 / 供应链层** | 通信安全、固件、OTA、多机器人协同 | 未认证消息、一台被感染后传染其他 | 中 | 学生容易上手 |
| **6. 人机交互层** | 开放指令被滥用、隐私泄露 | 通过对话或环境文字诱导越权动作 | 中高 | 人形相关 |

## 按攻击类型分类（更适合安全学生切入）

1. **数据投毒 / 后门攻击**  
   在遥操作数据、仿真数据或多模态指令中植入触发器。正常测试表现正常，遇到特定视觉/语言触发时执行危险动作。

2. **物理世界对抗攻击**  
   在机器人视野中放置对抗补丁、特定物体或文字，让感知或规划出错。

3. **越狱 / 提示注入攻击**  
   通过语音、文本或环境中的多模态提示，绕过安全限制，让机器人执行本应被拒绝的动作。

4. **传感器与系统攻击**  
   激光/声音欺骗传感器、ROS 2 消息注入、固件篡改等。

5. **运行时安全与防御**  
   在规划或控制层加入拦截机制，检测危险动作并阻止执行（适合攻击工作之后做）。

## 推荐的第一阶段研究问题（优先级从高到低）

### 1. 具身基础模型（VLA / World Model）的数据投毒与后门（最推荐）

- **思路**：把已有的材料基础模型安全思路迁移到机器人数据上。
- **攻击目标**：正常任务表现正常；遇到特定视觉或语言触发时，执行错误或危险动作。
- **参考**：通用模型后门（BadNets、Clean-Label 等）+ 生物/医疗领域已验证范式 + 现有具身越狱工作（BadRobot 等）。
- **硬件优势**：仿真中完成攻击，最后用机器狗或人形做关键触发验证。
- **目前缺口**：真实人形 / 机器狗上的系统性投毒工作很少。

### 2. 真实机器人上的多模态越狱 / 环境提示注入

- 在机器狗或人形视野中放置对抗补丁、特定文字海报，或语音 + 视觉组合触发越狱。
- 参考：BadRobot（ICLR 2025，真实机械臂）、TAPDreamer 等。
- 差异化：现有工作多在机械臂或仿真，人形和机器狗几乎空白。

### 3. ROS 2 / 通信层系统安全

- 学生最熟悉的方向，直接在现有平台上做消息注入、未认证通信攻击。
- 创新点相对弱一些，但容易出实验。

### 4. 运行时安全监控（第二阶段）

- 在规划或控制层加入危险动作检测与拦截，形成「攻击 + 防御」闭环。

### C. 通用模型安全参考（方法源头，可迁移）

学生可以先看这些通用攻击范式，再思考如何迁移到具身场景：

- **BadNets** (2017): 经典后门攻击。[arXiv:1708.06733](https://arxiv.org/abs/1708.06733)
- **Clean-Label Backdoor Attacks** (ICLR 2019): 无需修改标签的后门。[OpenReview](https://openreview.net/forum?id=HJg6e2CcK7)
- **BackdoorLLM** (2024): LLM 后门基准。[arXiv:2408.12798](https://arxiv.org/abs/2408.12798)

### D. 实验环境与数据参考

- **LIBERO**、**RoboTwin**、**VirtualHome**、**OmniGibson**：常用仿真基准
- **DROID**、**RH20T**、**RoboVQA**：常用真实机器人数据集
- 现有工作大多在**机械臂**上做真机验证，人形机器人和机器狗上的系统攻击仍很少

## 对学生的建议

- 第一阶段优先做 **模型层投毒/后门** 或 **规划层越狱**，不要同时铺开太多。
- 先在仿真环境跑通攻击，再选择关键案例上真实硬件验证。
- 和机器人方明确分工：安全学生负责攻击设计与评测，机器人团队负责接口与硬件执行。
- 成功标准不只是模型输出被操纵，还要证明物理行为真正发生改变。
- 建议阅读顺序：先看综述（Safety in Embodied AI）→ 再看 BadRobot 和 RoboJailBench → 最后结合通用后门方法思考迁移。
